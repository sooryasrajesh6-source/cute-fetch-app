# Cute API Project

A simple and cute web application built using HTML, CSS, and JavaScript that fetches data from an API using the Fetch API.

## Features

* Fetch API integration
* Dynamic data display
* Interactive button click
* Cute and responsive UI design
* Beginner-friendly JavaScript project

## Technologies Used

* HTML
* CSS
* JavaScript
* Fetch API

## API Used

https://jsonplaceholder.typicode.com/todos/1

## How It Works

When the user clicks the "Get Cute Data" button, the application fetches data from the API and displays it beautifully on the webpage.
